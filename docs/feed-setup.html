วิธีเปิด Feed

  1. เข้า Aion2Market เลือกตลาด Asia → Elyos → Fregion
  2. กด F12 → Network → Fetch/XHR จากนั้น Refresh แล้วหาคำขอที่ดึงรายการราคา/จำนวน Listings
  3. ยืนยันรหัส API แล้ว: 11507 เชื่อมกับ Game Server ID 1507 จริง โดยตัว Collector จะตรวจเซิร์ฟเวอร์ซ้ำก่อนดึงราคา
  4. ตรวจเงื่อนไขการใช้งานของผู้ให้ข้อมูล หรือขออนุญาตเก็บข้อมูลอัตโนมัติจากเว็บต้นทางตามที่จำเป็น
  5. หลังตรวจสิทธิ์แหล่งข้อมูลแล้ว ไปที่ Repository Variables (รหัสเซิร์ฟเวอร์ 11507 ตั้งไว้ใน Workflow แล้ว)
  6. เมื่อมีสิทธิ์เก็บข้อมูลแล้วจึงตั้ง MARKET_SOURCE_PERMISSION_CONFIRMED=true และ MARKET_DATA_COLLECTION_ENABLED=true
  7. ตั้ง Pages เป็น GitHub Actions เพื่อให้รายงานใหม่ขึ้นหน้าเว็บหลัง Collector ทำงาน แล้วสั่ง Deploy ครั้งแรกใน Actions

ตรวจ Feed ก่อนเปิด

ใน Actions มี Check market feed connectivity (one-shot) สำหรับทดสอบการตอบกลับและรหัสเซิร์ฟเวอร์จาก API โดยไม่บันทึกข้อมูลตลาด

ไม่แนะนำเปิด Collector โดยเดา ID เพราะจะนำราคาจากเซิร์ฟเวอร์อื่นมาแสดงผิดตลาด · Listing Drops ไม่ใช่จำนวนขายสำเร็จจริง · ต้องยืนยันสูตรคราฟและต้นทุนเพื่อคำนวณ ROI
